# 🧠 DataLemur SQL Practice

This repository contains my solutions to SQL practice problems from DataLemur.

I'm using these problems to strengthen my SQL fundamentals, improve my problem-solving skills, and get better at translating business questions into SQL queries.

## 🛠️ Topics Practiced

- 🔍 Filtering and sorting
- 📊 Aggregate functions
- 🗂️ GROUP BY and HAVING
- 🔗 JOINs and self joins
- 🧩 CTEs and subqueries
- 🔀 CASE statements and conditional aggregation
- 📅 Date functions
- 🪟 Window functions
- 🐘 PostgreSQL and MySQL syntax differences
- 💡 Multi-step SQL problems

## 📁 Repository Structure

Problems are organized into Markdown files containing:

- 📝 Problem description
- 💻 SQL solution
- 🧠 Concepts and patterns learned
- ⚙️ Important syntax or SQL dialect differences encountered

## 🎯 Goal

My goal is to move beyond simply learning SQL syntax and become better at breaking down analytical problems, identifying the required data operations, and building queries independently.

New problem sets are added as I continue practicing.
